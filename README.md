# 🧮 Calculadora Interactiva en C++

Programa de consola desarrollado en **C++** que permite realizar operaciones matemáticas básicas mediante un menú interactivo. Cuenta con personalización por nombre de usuario, estructura de control basada en `switch` y un ciclo iterativo `do-while` para realizar múltiples operaciones en una misma sesión.

---

## 🚀 Características

- 👤 **Personalización:** Solicita e integra el nombre del usuario durante la ejecución.
- ➕ **Operaciones Matemáticas:**
  - Suma
  - Resta
  - Multiplicación
  - División (con validación para evitar división entre cero)
- 🎛️ **Menú Interactivo:** Navegación por opciones implementada con la estructura `switch`.
- 🔄 **Flujo Continuo:** Uso de un bucle `do-while` que permite realizar varias operaciones sin reiniciar el programa.

---

## 🛠️ Tecnologías Utilizadas

- **Lenguaje:** C++ (C++11 o superior)
- **Entorno de Compilación:** Cualquier compilador C++ estándar (GCC, Clang, MSVC)
